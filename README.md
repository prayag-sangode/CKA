# Kubernetes 60-Day Lab Series

This repository contains a structured 60-day hands-on lab journey for mastering Kubernetes on a **kubeadm-based vanilla cluster** (1 master + 1 worker).  
Each lab is organized under `lab1`, `lab2`, … `lab60`.

Day 2: Bootstrapping a Multi‑Node Cluster with kubeadm

Day 5: Writing and Validating YAML Manifests for Kubernetes  
Day 6: Understanding Control Plane Components (API Server, etcd, Scheduler, Controller Manager)  
Day 7: Worker Node Components (kubelet, kube‑proxy, Container Runtime)  
Day 8: How Kubernetes Processes and Schedules Your Requests

Day 17: Managing ReplicaSets for Pod Scaling
