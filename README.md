# Kubernetes 60-Lab Lab Series

This repository contains a structured 60-Lab hands-on lab journey for mastering Kubernetes on a **kubeadm-based vanilla cluster** (1 master + 1 worker).  
Each lab is organized under `lab1`, `lab2`, … `lab60`.

Lab 2: Bootstrapping a Multi‑Node Cluster with kubeadm

Lab 5: Writing and Validating YAML Manifests for Kubernetes  
Lab 6: Understanding Control Plane Components (API Server, etcd, Scheduler, Controller Manager)  
Lab 7: Worker Node Components (kubelet, kube‑proxy, Container Runtime)  
Lab 8: How Kubernetes Processes and Schedules Your Requests

Lab 17: Managing ReplicaSets for Pod Scaling
